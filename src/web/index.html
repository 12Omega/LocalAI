Get Started

                        

                            Welcome to Local AI Development Environment! This tool helps you build software 
                            using locally-hosted AI models.
                        

                        

                            Let's set up your development environment in a few quick steps.
                        

                    

                

                
                
                

                    

                        
                        
                        

                            Enter the URL of your local LLM server (Ollama, llama.cpp, etc.)
                        

                        

                            
                        

                        

                    

                    
                    

                        
                        
                        

                            Name of the AI model to use (e.g., codellama:7b, deepseek-coder:6.7b)
                        

                    

                    
                    

                        
                        
                        

                            Ollama typically runs on http://localhost:11434
                        

                    

                

                
                
                

                    

                        
                        
                        

                            Some LLM servers require an API key for authentication. 
                            Leave blank if your server doesn't need one.
                        

                    

                    
                    

                        Note: API keys are encrypted and stored securely on your local machine.
                    

                

                
                
                

                    

                        
                        

                            
                            
                        

                        

                            Select the root directory where the AI will work on your projects.
                        

                        

                    

                    
                    

                        Tip: Choose a directory where you have write permissions. 
                        The AI will create and modify files in this directory based on your tasks.
